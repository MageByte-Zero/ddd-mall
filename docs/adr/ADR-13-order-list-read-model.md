# ADR-13 订单列表采用同库读模型

订单已持有成交快照、已接受的实付、履约和退款记录。列表通过订单库的有界只读查询组织这些事实，命令继续依靠领域聚合。订单页、展示行和部分退款汇总在同一短只读事务取得，库存只有原预占的本次观察，结束订单事务后发起一次独立批查。

逐单复用聚合详情能够取得数据，也会加载历史和完整明细。跨上下文组合只应请求拥有所需事实的接口，例如库存。现场向商品目录查询现名不能还原某笔已成交订单。独立投影可隔离读负载，但要维护首次构建、更新顺序、恢复与延迟政策。当前保留原存储和字段口径，通过分页和预览限制输出。是否引入独立投影由实际负载与允许的新鲜度决定。

如需暂停此路径，可停用列表消费者，保留已有详情及命令。本讲无投影表及数据迁移。列表查询共享订单库的资源，库存批查有独立超时；对照报表如果需要跨上下文同一时点，须另定义可辩护的时间口径。
