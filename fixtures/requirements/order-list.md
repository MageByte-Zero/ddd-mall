# 已付款订单列表

售后和履约核对使用。沿用同一 SKU 的订单行 PR-A 一根、PR-B 两根，原成交单价 ¥50，实付 ¥150。

- 按指定用户只读已接受付款且未逻辑删除的订单。渠道已收款、订单尚未接受时暂不入列。按订单 ID 倒序翻页，默认且最多 20 单，每单预览前三行，超出时提示进入详情。
- 商品名称、数量、单价与行身份读原成交快照。订单实付与履约状态由订单库提供。旧整单退款的原履约状态、申请状态、结果和金额分别显示。部分退款的在途金额包含登记与未知，成功计入已退，最终拒绝退出计总。
- 有发货记录时核实可见行的原预占号。库存仍为 `RESERVED` 时，订单仍可显示已发货，出库尚待确认。`CONFIRMED` 表示匹配原预占的出库已确认。未发货不查。旧行无原引用标未核验，批查查不到标未找到，SKU 或数量不符标信息不匹配，批查失败或超时标暂不可核验。
- 库存只报告本次单独观察，不覆盖订单、退款或成交事实。批查异常保留订单清单，下次刷新重新核实。批查最多 60 个引用，一页最多发起一次；订单本地读失败由查询报错。
- 列表和库存查询没有领域状态变更、库存动作或消息产生。这两个契约用于可信内部调用。用户筛选负责限制查询范围，接入方负责调用授权。
